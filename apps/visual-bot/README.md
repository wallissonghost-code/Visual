# Visual Bot

Módulo independente para auditoria visual, estrutural e de código de sites e repositórios.

## Responsabilidades

- auditoria de página publicada;
- auditoria estática de repositório;
- detecção de código morto e referências órfãs;
- detecção de duplicações e handlers redundantes;
- cruzamento entre código-fonte e comportamento entregue ao navegador.

O Visual Bot não deve importar nem depender de implementação interna do Security Bot.
